# smt — оверлей-подсказчик для 2048

Читает доску 2048 прямо с экрана и рисует поверх неё стрелку с лучшим ходом.
Прототип на Python: на нём отлаживается вся обвязка «захват → распознавание →
решатель → оверлей», которую потом можно переиспользовать для других игр.

## Как это работает

```
capture.py  снимок экрана (mss) + отсев кадров, пойманных посреди анимации
board.py    поиск доски по цвету фона, чтение 16 клеток по палитре плиток
solver.py   expectimax с кешированием узлов, «змейчатая» оценочная функция
overlay.py  прозрачное клик-сквозное окно поверх всех остальных
main.py     склейка: тяжёлый цикл в фоновом потоке, отрисовка в основном
```

Распознавание обходится без OCR: в классической вёрстке 2048 у каждого
номинала плитки свой уникальный цвет фона, поэтому клетка читается
сопоставлением доминирующего цвета с таблицей.

## Запуск

Установка зависимостей:

```bash
py -m pip install -r requirements.txt
```

Запуск (2048 должен быть открыт на экране):

```bash
py src/main.py
```

Полезные флаги:

| Флаг | Значение |
|---|---|
| `--monitor N` | номер монитора, если их несколько (по умолчанию 1) |
| `--depth N` | фиксированная глубина поиска вместо адаптивной |
| `--interval S` | пауза между кадрами в секундах (по умолчанию 0.25) |

## Заметки

- **Глубина поиска адаптивная**: чем меньше пустых клеток, тем глубже смотрим,
  потому что ветвление падает вместе с их количеством. Обычно 4–6 полуходов.
- **Окно не перехватывает ввод** — играть можно как обычно, подсказка просто
  висит сверху.
- **Кириллица в консоли Windows** может падать на cp1252. Если ловите
  `UnicodeEncodeError`, выставьте `PYTHONIOENCODING=utf-8`.
- Fullscreen exclusive приложения захватить не получится — 2048 в окне браузера
  проблем не вызывает.
